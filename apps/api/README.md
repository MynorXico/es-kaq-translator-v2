# apps/api

FastAPI service exposing the Spanish<->Kaqchikel translation API, deployed
as a Lambda container behind API Gateway.

Not yet scaffolded — see [`docs/adr/0001-initial-architecture.md`](../../docs/adr/0001-initial-architecture.md).

Code, comments, and tests are written in English; API responses meant for
end users (error messages shown in the UI, etc.) are written in Spanish.
